# 日程データの作り方

画面が読むのは `public/data/tour.json` だけです。これを `scripts/build-tour.mjs` が、次の 2 つから作ります。

| ファイル | 中身 | 誰が書くか |
| --- | --- | --- |
| `tours/tour.txt` | 公式サイトの日程表の貼り付け | 手で貼る |
| `data/venues.json` | 会場ごとの住所・座標 | 住所は手で書く。座標は自動 |

```bash
npm run build-tour                 # .cache/ に経路があればそれを使う
npm run build-tour -- --force      # 経路を OSRM から取り直す
npm run build-tour -- tours/x.txt  # 別の入力ファイルから作る
```

## 入力(tours/tour.txt)

「日時」の行の次に日時、「会場」の行の次に会場名があれば読めます。ほかの行は無視します
(「対戦カード」「チケット」のリンクだけ拾って、一覧に出します)。並び順は問いません。日時順に並べ直します。

```text
日時
2026年11月25日 (水) 17:30開場18:30開始
会場
山形・INPEX酒田アリーナ

* [対戦カード](https://...)
* [チケット](https://...)
```

読み方は `scripts/parse-tour.mjs`、そのテストは `scripts/parse-tour.test.mjs` にあります。

## 会場(data/venues.json)

キーは、入力の会場名そのまま(全角の空白・括弧は半角にそろえたもの)です。

```json
{
  "山口・岩国市総合体育館": {
    "address": "山口県岩国市平田一丁目40-1",
    "lat": 34.153946,
    "lng": 132.187683,
    "note": "位置は住所から(国土地理院の住所検索)"
  }
}
```

- 辞書に無い会場があると、`build-tour` は止まって、足すべきキーのひな形を出します。**`address` だけ書けば十分**です。
  `lat` / `lng` が無ければ、国土地理院の住所検索で引いて、このファイルに書き戻します。
- 会場名から住所を自動で引くことはしていません。名前だけの検索は、同じ名前の別の施設に当たることがあるためです
  (「青森県武道館」で三沢市の武道館が返る、など)。
- 住所から引いた位置がずれているときは、`lat` / `lng` を手で直します。
- `"approx": true` を付けると、一覧に「位置は概略」と出ます(正確な位置が分からず、近くの地点で代用したとき用)。
- `note` は覚え書きです。画面には出ません。

## 経路

- 隣り合う 2 会場ごとに、OSRM の公開サーバー(`router.project-osrm.org`、車)へ問い合わせます。
  公開サーバーはデモ用なので、CI からは呼びません。結果は `.cache/` に置き、会場の座標が変わった区間だけ取り直します。
  別のサーバーを使うときは、環境変数 `OSRM_URL` で指定します。
- 公開サーバーでは「フェリーを使わない」という指定ができません。そこで、結果にフェリーの区間が混じったら
  `tour.json` の `legs[].ferry`(メートル)に入れ、一覧に「フェリー○km を含む」と出します。
  出たときは、その区間を Google マップのリンクで確かめてください。
- 距離・時間は OSRM の見積もりです(渋滞・休憩は含みません)。
- 線は 30m ほどの誤差で間引いています(`SIMPLIFY`)。

## Google マップのリンク

`src/gmaps.js` が [Maps URLs](https://developers.google.com/maps/documentation/urls/get-started) の形で作ります。
行き先は「住所 + 会場名」の文字列で渡します。

- 経由地は 1 本のリンクにつき 9 か所までなので、会場が 12 以上あると「1→11」「11→14」のように分かれます。
- スマホのブラウザでは、経由地が 3 か所までしか反映されないことがあります。そのときは区間ごとのリンクを使ってください。

## tour.json の形

```json
{
  "stops": [
    { "date": "2026-11-25", "weekday": "水", "open": "17:30", "start": "18:30",
      "pref": "山形", "name": "INPEX酒田アリーナ", "address": "…", "lat": 38.89, "lng": 139.82,
      "links": { "card": "https://…", "ticket": "https://…" } }
  ],
  "legs": [
    { "from": 0, "to": 1, "distance": 298800, "duration": 14200, "coordinates": [[139.82, 38.89], …] }
  ]
}
```

`legs[i]` は `stops[i]` から `stops[i + 1]` への区間です。`distance` はメートル、`duration` は秒。
同じ会場での連戦は、`distance` が 0 で `coordinates` が空になります。
